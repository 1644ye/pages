# Shopify Page Studio 0.1.7

Windows / DeepSeek Harness 0.2.0-rc.2。tag：`dsh-v0.1.7`。

- 入口改为 DSH 原生侧栏“页面工作台”，内容在宿主主区显示，取消左下角悬浮按钮和覆盖弹层，不打开外部网页。

- 修复 0.1.4 健康文件路径不一致引起的误回滚；恢复助手在激活已确认或更新记录已被替代时退出。
