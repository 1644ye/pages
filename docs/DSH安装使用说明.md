# Page Studio DSH 插件：安装与使用

## 本次交付

插件版本：0.1.2。目标环境：Windows，DeepSeek Harness 0.2.0-rc.2。
这是可安装的 DSH bundle，和原来的“免安装离线 HTML 版”是两个交付物。
DSH 插件使用你在宿主中配置的 DeepSeek，可能产生正常模型用量；不会另外要求 API Key。

## 三分钟安装

1. 完整解压 `PageStudio-DSH-0.1.2-Windows.zip`。
2. 双击 `安装到DSH.cmd`。它使用本机已安装的 DSH CLI，把同目录下的 `.tgz` 安装到 `desktop` Profile。安装过程中请等待窗口显示成功；版本不兼容时不要强制跳过检查。
3. 保存 DSH 中正在进行的工作，然后由你正常关闭并重新打开 DSH。**安装程序不会替你结束 DSH 或其他任务。**
4. 在 DSH 主界面找到左下角的 `Page Studio · 页面生成` 按钮，点击打开插件工作区。

如果安装位置不是标准目录，可以在终端中使用实际 DSH CLI：

```powershell
dsh plugin --profile desktop add "解压目录\dsh-shopify-page-studio-0.1.2.tgz"
```

只有 DSH CLI 已加入 PATH 时，上面的 `dsh` 简写才有效。本机检测到的标准入口是
`%LOCALAPPDATA%\Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd`。
若你使用其他 Profile，把 `desktop` 替换为其真实名称。不要将其他应用的仓库或安装目录当作插件路径。

## 页面生成与编辑

1. 填写参考描述的标题和内容、最高折扣，按需填写邮箱、日期和补充要求。品牌名仅用于营销/SEO 与提示词，七个生成页面不写品牌名称。
2. 查看实际模型。默认使用宿主已配置的 DeepSeek。首次生成建议将“现有会话”留空，插件会新建专用会话。
3. 可点“预览发送内容”查看即将发送的要求。点击“DSH 对话生成页面”，或直接点击“生成并导出 XLSX”。
4. 正文与思考分开显示，最终回合完成并通过结构验证后才接受结果。错误时会显示真实原因，不用离线模板补成成功。
5. 如需停止，点“停止生成”。取消后不自动导出。需要重试时重新点击生成，不会无限重试。
6. 选择页面预览，展开 HTML 编辑器后修改并保存；再导出当前版本。重新导出不会调用模型。
7. “结果版本”可切回已保存的版本。“继续修改要求”可以在明确选择的同一会话中修改当前完整结果。

## 文件导入

主要导出是 `Pages-and-Menus-<唯一标识>.xlsx`：

- `Pages`：8 个页面；默认 Published 为 TRUE，可以取消勾选改为草稿。
- `Menus`：8 个目录项，分为 About、Information 两组，通过 handle 关联页面。

宿主先把文件写到插件用户数据目录，再提供下载链接。若浏览器不允许异步自动下载，点击“文件已生成”链接即可，不需要重新生成内容。
将整个 XLSX 交给 Shopify 的 Matrixify 导入，之后在主题页脚选择 About / Information 菜单。
JSON 与首页/SEO 文案仍可单独下载。思考内容和工具日志不导入页面。

Contact Us 保留你提供的固定表单；它只跳转首页，不发送邮件或保存留言。正式使用前请检查客服时间和实际业务信息。

## 提示词工作台

原来的内容多选、全选、源网址、重点选择和尺码表选项仍保留。
生成或粘贴提示词后，可以填写标题、分类标签并保存；变量统一写成 `{{变量名}}`。
“变量默认值”和“本次变量值”使用 JSON 对象，例如 `{"产品":"连衣裙"}`。
先预览展开内容，再点“直接运行 DeepSeek”。缺少必填变量时不会发送请求。
尺码表要求输出可直接粘贴的纯 HTML，不含 JavaScript、CSS、style 属性或 Markdown 围栏，不编造尺寸。

首版包含保存、编辑、变量预览和直接运行；AI 优化候选、应用优化、隔离试运行增强项未交付。

## 自动更新与数据

更新设置默认开启自动检查与自动安装。启动后及宿主运行时每 6 小时检查一次，宿主关闭后不继续检查。
目前 GitHub 仓库尚未提供，界面会显示“source-unconfigured”；这不等于“已是最新版”。
后续确定固定的 `owner/repo` 并完成真正 Release 发布后，检查器才有可用发布源。
稳定通道跳过草稿/预发布，选择最高兼容版本；下载校验大小、SHA-256、包身份和版本。
只有兼容、数据可回退且发布信息声明已验证恢复的版本才进入自动安装。
正在生成、导出或有未保存编辑时等待。现有版本更新需要重启，界面会如实显示待重启。

用户提示词、设置、历史和导出文件位于：
`%USERPROFILE%\.dsh\page-studio\<Profile>\`。
它们不放在插件安装目录，卸载插件不会删除这些文件。
当前数据 schema 为 1；可重复读取，遇到未知 schema 会停止写入。

更新前会保存旧版包及数据恢复点。受控助手在旧宿主退出后检查新版健康标记；若新版未能健康启动，重新安装本插件的旧包，并保留兼容的最新数据。
恢复完成仍可能需要你再次重启 DSH，助手不强制终止宿主。失败版本会被阻止继续自动安装。
SHA-256 用来发现下载损坏，不代表能防止发布账号被攻破。

## 卸载与手动恢复

在 DSH 插件管理器停用/卸载，或使用：

```powershell
dsh plugin --profile desktop remove dsh-shopify-page-studio
```

恢复时，可重新安装 `updates\rollback-<版本>.tgz`。一般不要覆盖用户数据；仅在数据文件损坏时使用对应备份。

## 验证边界

真实宿主、真实模型、文件与本地升级/回滚证据见 `dsh-migration.md`。
自动界面检查被电脑操作工具的安全限制停止，因此安装后需要你亲自确认主界面的 Page Studio 入口。
没有 GitHub 地址时不声明远端推送、Release、远端 CI 或跨网络自动升级已通过。
